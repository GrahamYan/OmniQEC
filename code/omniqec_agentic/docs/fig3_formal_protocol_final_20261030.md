## 2. 任务线路与测量

| 项 | 值 |
|---|---|
| 任务 | 同一个码的两个 block：T = 12 轮综合征提取，在第 1–11 轮之后各做一层 transversal 逻辑 CNOT（block 0 控制、block 1 目标），共 11 层门；两个 block 联合解码 |
| 基 | X 基、Z 基各一条线路，制备与读出和存储实验相同；探测器经过 CNOT 时按 X_c → X_c X_t、Z_t → Z_c Z_t 传播 |
| 轮数 | T = 12，所有码、所有阶段（搜索、终局、补测）都一样 |
| 噪声 | 均匀电路级噪声 `uniform_paper_v1`：每个线路位置 p = 0.005；双比特门方向 `control_first`；只用这一个噪声点 |
| 失败判定 | 一个基里 2k 个逻辑观测量有任何一个出错，就记该基失败 |
| 指标 | P = 1 − (1 − F_X/S_X)(1 − F_Z/S_Z)；p_LPR = 1 − (1 − P)^(1/(2k·T))，即每逻辑比特每轮的错误率。2k 是两个 block 的逻辑比特数，T = 12 |
| 置信区间 | 每个基取 Wilson 区间（z = 1.96），再经同一单调变换得到 p_LPR 的 95 % 区间 |
| 合并 | 同一个码的独立样本：每个基把失败数和发数分别相加，再算一次 p_LPR |

### 2.1 综合征提取线路（SEC）

| 项 | 值 |
|---|---|
| 策略 | `twobasis_nonint_v1`：每轮两个基都测，不交错 |
| 候选层序 | 每个基 16 个 |
| 认证 | ISD，400 次迭代 × 3 个种子，迭代倍率 4.0 |
| 细化 | 前 4 名再各跑 2000 次迭代 |
| 线路距离 | d_ext 截到 d_search |

### 2.2 解码器

`telescoping_cpu_v1`（telescoping-decoder@c97099b，包版本 0.1.0），所有测量用同一份配置：

| 阶段 | 参数 |
|---|---|
| A | iters 100，τ 5.0，α_max 0.99 |
| B | iters 100，runs 40，quorum 3，stop_nconv 5，γ0 0.1（γ0 iters 80），γ center 0.21，γ width 0.9，α_max 0.9，τ 5.0，use_memory 开，min_cost_select 关 |
| C | seeds 10，τ 5.0 |
| S3 | GARI；S1、S2、S4 关 |
| 其他 | 不收敛判失败（`nc_policy = fail`）；每个 shard 单进程 |

### 2.3 发数与早停

| 项 | 搜索阶段（慢环） | 终局 |
|---|---|---|
| 每基发数上限 | 25 000 | 25 000 |
| 早停 | `pilot10x_maxerr100_v3`（见下） | 不早停，测满 |
| 切分 | 16 个 shard | 128 个 shard |
| 随机数命名空间 | 搜索默认 | `final_confirmation_v1`（与搜索不相交） |

搜索阶段的早停规则 `pilot10x_maxerr100_v3`：
- 先测 2 000 发/基，250 发一批。
- 测完这 2 000 发后，若 p_LPR 的 CI 下界超过当前最好码 CI 上界的 10 倍（ε = 9），就停。
- 每个基都攒到 100 次失败时也停；这条在每批之后都检查，包括前 2 000 发期间。
- 其余候选测满 25 000 发/基。
- 序贯停止带来的偏差不做校正。

看门狗：
- 解码超过 8 s/shot，判 `decode_infeasible`；不设每比特代价上限。
- shard 超时 1800 s，建线路超时 3600 s，瞬时错误重试 1 次。

## 3. 码的表示与快环检查

| 项 | 值 |
|---|---|
| 码族（spec 语法） | `bb`、`hgp`、`lp_abelian`、`lp_nonabelian`。码族是 LLM 写 spec 用的语法，不是数学分类 |
| 程序形式 | `construct(rng)`：LLM 写构造程序，每个程序用 40 个随机种子各运行一次 |
| 结构检查 | 矩阵为二维；CSS 对易；k > 0；n_data + n_checks ≤ N；Tanner 图连通；**check weight ≤ 6**（构造期硬上限） |
| 去重 | 先按 code hash 去重，跨程序、跨种子；慢环前再按 pynauty 规范形去掉同构孪生，跨码族生效 |
| 码距代理 d_search | `css_permutation_systematic_v2_independent_xz`，X、Z 各 4 个种子 × 120 次迭代 |
| 结构质量 | Q = k · d_search² |
| 存档 | MAP-Elites，格子按 (k, d_search) 划分，每格保留最先达到最高 Q 的码 |
| 结构保留 | 在 (k, d_search, −w) 三轴上取 Pareto 层；最多 24 个精英，每格最多 2 个，要求 k ≥ 2 |

## 4. 一轮搜索

| 步骤 | 设置 |
|---|---|
| 1. 编排器 | 带工具的循环，工具预算 32 次。输出本轮计划：码族配额、策略配比，可点名候选（最多 4 个） |
| 2. 生成器（快环） | **每轮 4 代**，每代调用 1 次 LLM，要求 **24 个程序**（不足时追问补齐）。每个程序 **40 个种子**，每轮共 3 840 次构造。每轮开始前先评估 5 个内置种子程序。第 2–4 代的 prompt 包含本轮前几代的快环结果；父代等轮级上下文在一轮内不变 |
| 3. 慢环选码 | **每轮 7 个名额 = 3 个结构 + 4 个运行时**（§4.1） |
| 4. 慢环测量 | 按 §2 测门线路 |
| 5. reflector | 每轮末调用 1 次，总结给下一轮的编排器 |
| strict 模式 | 任何一代没收齐 24 个程序，整轮从 checkpoint 重来，最多 8 次 |

### 4.1 慢环选码

| 项 | 值 |
|---|---|
| 候选池 | 本轮各格子的胜者 + 结构精英 |
| 剔除 | 已测过的码；同构孪生；d_search < 5；check weight > 6；运行时名额另要求 d_search/√n ≥ 0.25 |
| 3 个结构名额 | 前沿的高 k 端点、高 d_search 端点、最轻的格子；不足时用未占用格子的代表补 |
| 4 个运行时名额 | 按 `expected_plpr_v1` 排序：同 (w, d_search) 类已测码的 log10 p_LPR 均值，向同权重均值和全局均值收缩（n0 = 3）；没有实测数据时按 Q 排 |
| 空名额 | 保持空，不补 |

### 4.2 生成器 prompt 的上下文

- 编排器给的策略和码族配额；
- 比特预算 n_data + n_checks ≤ N；
- 四个码族的语法和比特数公式；
- 构造约束，含 check weight ≤ 6；
- 本轮存档（每格一个码）；
- 最近程序的快环结果，标出已测过的码和同构孪生；
- 上一轮慢环队列的统计：填了几个名额，候选里有多少孪生、已测、超权重；
- 构造失败的类型和建议；
- 已实测的码和 p_LPR；
- "不具竞争力"列表：p_LPR ≥ 当前最好码 2 倍且 CI 不重叠的码和类，最多 12 行；
- 父代：16 个候选（6 个结构 + 6 个运行时 + 4 个多样性），prompt 中展示前 12 个，每个附 spec 和完整程序；
- 按 check weight 统计的实测结果。

| 臂 | 模型 | 接入 | temperature | max_tokens | 超时 |

## 7. 终局（第 30 轮之后）

| 项 | 值 |
|---|---|
| 入围 | 2 个结构端点（满足 w ≤ 6）+ 4 个已测最好的码 + 常驻参考码（N = 144 为 BB72，N ≥ 288 为 BB144；已入围时不重复）。每次搜索 6–7 个 |

| 冠军 | 状态正常、不是参考码的入围码里，取 (p_LPR, CI 上界) 最小的；并列时保留原顺序。冠军选定后不再更换 |

## 8. 冠军补测

1. 目标：每个冠军每个基至少 30 次失败。
2. 第一轮发数：取终局 25k 里较弱一基的失败数 f。
   - f ≥ 30：不补；
   - f = 0：补 500k；
   - 其他：补 min(500k, 50k · ⌈(45 · 25k / f) / 50k⌉)，即按"期望 45 次失败"估算，向上取到 50k 的整数倍。
3. 按点统一：同一个 N 的三个臂都补该点三臂中最大的发数。
4. 合并：补测与终局 25k 合并（§2）。合并后若仍有冠军较弱一基 < 30 次，再补一轮：45 · 总发数 / f_min − 总发数，向上取到 50k，上限 500k，仍按点统一。
5. 种子：每轮补测用独立的种子命名空间，与搜索、终局都不相交。

各点每基发数（含终局 25k 的合计）：

| N | 补测 | 合计 |
|---|---|---|
| 60、98、144 | 不需要（终局时每基已 ≥ 57 次失败） | 25k |
| 180 | 50k | 75k |
| 220 | 100k | 125k |
| 260 | 150k | 175k |
| 288 | 300k | 325k |
| 320 | 500k | 525k |
| 360 | 500k + 第二轮 350k | 875k |

最终 27 个冠军每基最少 49 次失败。
