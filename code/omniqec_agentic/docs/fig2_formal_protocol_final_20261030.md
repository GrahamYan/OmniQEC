# Fig.2 实验设置与超参数

本文列出 Fig.2 正式实验实际使用的设置与超参数，供撰写附录使用。

---

## 1. 总体设置

| 项 | 设置 |
|---|---|
| 物理比特预算 N | 60、98、144、180、220、260、288、320、360 |
| 预算的含义 | 总物理比特数 = 数据比特数 + 校验行数（每个校验行一个测量辅助比特），即 n + m_X + m_Z ≤ N |
| LLM 后端 | Claude（claude-opus-5）、DeepSeek（deepseek-v4-pro）、GPT（gpt-5.6-sol） |
| 每个（N, 后端） | 一次 30 轮的搜索，之后一次终局测量 |
| 参考码 | BB [[72,12,6]]（N = 144）、BB [[144,12,12]]（N = 288），只参与测量对比，不出现在提示词中 |

---

## 2. 码空间

LLM 生成的每个程序返回一个码描述（spec），由以下四种构造之一生成 H_X 和 H_Z。

| 构造 | 参数 | 校验矩阵 | 总比特数 | 约束 |
|---|---|---|---|---|
| BB（二元自行车码） | 环面 ℓ×m；A、B 为 x、y 的单项式之和，每项 xᵃyᵇ | H_X = [A \| B]，H_Z = [Bᵀ \| Aᵀ]，x = S_ℓ ⊗ I_m，y = I_ℓ ⊗ S_m | 4ℓm | A、B 总项数 4–9；取模后无重复项 |
| HGP（超图积码） | 两个经典校验矩阵 H1（m1×n1）、H2（m2×n2） | H_X = [H1 ⊗ I_{n2} \| I_{m1} ⊗ H2ᵀ]，H_Z = [I_{n1} ⊗ H2 \| H1ᵀ ⊗ I_{m2}] | (n1+m1)(n2+m2) | 每行、每列的度为 2–4；无重复行 |
| LP Abelian（阿贝尔群提升积码） | 有限阿贝尔群 G = C_q1 × C_q2 × …；原型矩阵 A（m_A×n_A）、B（m_B×n_B），元素属于 F₂[G] | H_X = [L(A ⊗ I_{n_B}) \| R(I_{m_A} ⊗ B*)]，H_Z = [R(I_{n_A} ⊗ B) \| L(A* ⊗ I_{m_B})]；L、R 为左、右正则表示，* 为转置加逐元素取逆 | (n_A+m_A)(n_B+m_B)·\|G\| | A、B 形状各自取 1×1、1×2、2×1 或 2×2；每个元素是 1–8 个不同群元素之和；A、B 中的群元素须生成整个 G |
| LP Non-Abelian（非阿贝尔群提升积码） | 同上，G 取自群目录：二面体群 D_n、A4、S4、亚循环群 C_m ⋊ C_n，以及 C_m 与上述群的直积 | 同上 | 同上 | 同上；另外 \|G\| ≤ N/4 |

所有候选须满足：H_X H_Zᵀ = 0；k ≥ 1；总比特数 ≤ N；Tanner 图连通。不限制检查权重（§7 的门槛除外）。

两个提升积构造在 A、B 均为 1×1 时即为双块群代数（2BGA）码；其中群为阿贝尔群且同构于至多两个循环群的直积时，与 BB 码等价（循环群对应 ℓ = 1）。

## 3. LLM 搜索

| 项 | 设置 |
|---|---|
| 搜索轮数 | 30 |
| 每轮生成 | 4 代，每代 24 个程序（共 96 个） |
| 程序形式 | Python 函数 `construct(rng)`，返回一个码描述 |
| 每个程序的随机种子数 | 40（每轮最多 3,840 个候选码） |
| 采样温度 | Claude 1.0；DeepSeek 0.45；GPT 1.0 |
| 最大输出长度 | 64,000 token |
| 单次调用超时 | 900 s |
| 每轮编排器工具调用上限 | 32 |
| 提示中的反馈 | 结构层面：档案质量分、近期程序、结构检查失败原因；电路层面：慢环实测的 plpr；另附父代程序 |
| 每代父代程序 | 16 个 = 结构前沿 6 个 + 实测最好 6 个（每个检查权重类最多 2 个）+ 多样性 4 个 |
| 初始种子程序 | 5 个：BB（3×5 环面，6 项）、HGP（4×4 循环矩阵作种子）、LP Abelian（C3×C3，[[27,2,4]]）、LP Non-Abelian（D6，[[24,8,3]]）、LP Non-Abelian（C7⋊C3，[[42,4,5]]） |

---

## 4. 快环（结构评估）

| 项 | 设置 |
|---|---|
| 码距估计 d_search | 置换–系统化形式的随机逻辑算子搜索，X、Z 两侧独立；4 个种子 × 每种子 120 次迭代，取最小值（上界） |
| 质量分 | Q = k · d_search² |
| 结构前沿 | 三个目标 (k, d_search, −w) 上的非支配集，w 为最大检查权重；精英池 24 个 |
| 进入慢环的门槛 | d_search ≥ 5；结构通道还要求 k ≥ 2 |
| 去重 | 已测量或已排队的码不再进入慢环，按 Tanner 图在比特与校验重排下的规范形判断 |

---

## 5. 慢环（电路级评估）

| 项 | 设置 |
|---|---|
| 每轮名额 | 6 个 = 2 个结构端点（前沿上 k 最大、d_search 最大的码）+ 4 个按预测 plpr 排序的候选 |
| 每码最多测量 | 每个基 25,000 发（分 16 片） |
| 早停：初测 | 先测每个基 2,000 发（每片 250 发） |
| 早停：相对淘汰 | 若候选 plpr 的 95 % 区间下界 ≥ 10 × 当前最好码的区间上界，则停止测量（ε = 9） |
| 早停：失败上限 | 每个基累计失败数达到上限即停止；上限 100（部分运行为 30，见 §7） |
| 单发解码时间预算 | 8 s |
| 结果用途 | 慢环 plpr 用于排名和反馈，不作为报告值 |

## 6. 电路级测量（慢环、终局与补测共用）

### 6.1 噪声与线路

| 项 | 设置 |
|---|---|
| 噪声模型 | 均匀电路级噪声，单一参数 p：每次复位后单比特去极化 p；每层 CNOT 后双比特去极化 p；每次辅助比特测量前以概率 p 翻转；数据比特最终读出前以概率 p 做与记忆基共轭的翻转；无空闲噪声 |
| 物理错误率 | p = 0.005 |
| 记忆实验 | X 基、Z 基各一个，各自跟踪 k 个逻辑可观测量 |
| 轮数 | T = max(12, d_search) 轮带噪综合征提取，随后读出全部数据比特 |
| 综合征提取 | 每个校验行一个专用辅助比特，每次使用前重新制备；每轮先测全部 X 型校验，再测全部 Z 型校验 |
| 门序选择 | 每个记忆基生成 16 个候选门序，用 ISD 估计电路距离：400 次迭代（按扩展核维数 × 4 取较大值），3 个种子取最小；前 4 名再用 2,000 次迭代复核，取最好者 |

### 6.2 解码器

telescoping 解码器 CPU 配置，第三阶段使用 GARI 图变换，第一、二、四阶段关闭；BP 不收敛的样本计为失败。包内参数：

| 参数 | 值 | 参数 | 值 |
|---|---|---|---|
| a_iters | 100 | b_runs | 40 |
| a_tau | 5.0 | b_iters | 100 |
| a_alpha_max | 0.99 | b_quorum | 3 |
| b_gamma0 | 0.1 | b_stop_nconv | 5 |
| b_gamma0_iters | 80 | b_tau | 5.0 |
| b_gamma_center | 0.21 | b_alpha_max | 0.9 |
| b_gamma_width | 0.9 | b_use_memory | true |
| c_n_seeds | 10 | c_tau | 5.0 |

### 6.3 指标

| 项 | 定义 |
|---|---|
| 块错误率 | p_block = 1 − (1 − p_X)(1 − p_Z)，p_X、p_Z 为两个记忆实验中任一逻辑可观测量出错的比例 |
| 每逻辑比特每轮错误率 | p_LER = 1 − (1 − p_block)^(1/(k·T)) |
| 置信区间 | 每个基 Wilson 95 % 区间（z = 1.96），按同一映射换算到 p_LER |

## 7. 运行间的设置差异

除下表各项外，所有运行的设置相同。

| 设置 | 适用范围 |
|---|---|
| 失败上限 30（默认 100） | N ≥ 288 的部分运行，自某轮起或全程 |
| 检查权重门槛 w ≤ 8（只限制进入慢环） | 与失败上限 30 同时启用 |
| 初测阶段不检查失败上限（默认在初测阶段也检查） | DeepSeek N = 60、98 与 GPT N = 60、98、144 全程如此；另有部分运行的前若干轮如此 |
| 解码代价上限：单发解码超过 0.10 CPU 秒 × 数据比特数（不低于 8 s）即判为不可解码 | GPT N = 180 第 14–29 轮、N = 220 第 13–27 轮、N = 260 第 11–25 轮；Claude N = 320 第 2–8 轮；另有 10 个运行各 1–3 轮 |
| 单片解码时限：搜索 8 h、终局 4 h | 部分运行；因时限被误判的终局候选已在无时限下重测 |

## 8. 终局

| 项 | 设置 |
|---|---|
| 候选 | 2 个结构端点 + 4 个慢环实测 p_LER 最好的码 + 参考码（N = 144 为 BB [[72,12,6]]，N ≥ 288 为 BB [[144,12,12]]） |
| 测量 | 每码每个基固定 25,000 发（分 128 片），不早停，使用与搜索不相交的随机种子 |
| 轮数 | 同 §6，T = max(12, d_search) |
| 冠军 | 非参考码中终局 p_LER 最低者；并列时取区间上界较小者 |
| 精确码距 | n ≤ 100 且 d_search ≤ 8 的候选用 MILP 求解（每码 5 s） |
| 无法解码的候选 | 超出解码预算者不参与排名 |

---

## 9. 补测

对 N ≥ 180 的冠军追加测量，以提高统计精度。补测与终局设置相同，只是发数不同：固定发数、不早停、使用新的随机种子。冠军不重选。补测计数与终局计数相加，再计算 p_LER 和置信区间。

| N | 180 | 220 | 260 | 288 | 320 | 360 |
|---|---|---|---|---|---|---|
| 每个基的补测发数 | 150,000 | 250,000 | 500,000 | 500,000 | 850,000 | 1,700,000 |
| 合并后每个基的总发数 | 175,000 | 275,000 | 525,000 | 525,000 | 875,000 | 1,725,000 |

同一 N 下三个后端的补测发数相同。参考码只用补测数据：BB [[72,12,6]] 每个基 50,000 发，BB [[144,12,12]] 每个基 100,000 发。

## 10. 结果呈现

| 项 | 设置 |
|---|---|
| 纵坐标 | −log10(p_LER)；N ≤ 144 用终局值，N ≥ 180 用终局与补测的合并值 |
| 横坐标 | 预算 N |
| 气泡面积 | 正比于 k·d_search²/n |
| 拟合线 | 每个后端用 9 个预算点对 −log10(p_LER) 做不加权最小二乘直线拟合，仅作描述；参考码不参与 |
