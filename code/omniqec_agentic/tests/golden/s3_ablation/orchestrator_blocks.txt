# Tool catalog

## acquisition_score(code_hashes: array)  [scope=read]

Deterministic baseline order for the FOUR runtime slow slots (code_hash
prefixes). baseline_order is the full archive queue minus candidates that
already carry a measurement (fixed shots: nothing is re-measured) and
minus schedule_catastrophic ones; it is exactly the list the plan
validator checks. Promoting baseline_head needs no rationale; naming any
other candidate needs a per-item cited rationale in the plan. scores
report the requested hashes only (measured ones are flagged, not
ranked into the baseline). This tool has no authority over the two
structural endpoint slots, which the (k, d_search, -weight) reducer fills;
degraded_* candidates are scored normally.

Example call: `acquisition_score(code_hashes=["a41f00b2", "9c00d1ee"])`

## bandit_status()  [scope=read]

Strategy-arm suggestion and statistics (UCB1, 03 §6.4). The mix is an
informed signal: deviating from it requires a cited rationale in your
plan; every arm keeps the epsilon_arm floor.

Example call: `bandit_status()`

## budget_status()  [scope=read]

The four ledgers (tokens / slow shots / wall clock / turns): used so
far and configured caps. Plans exceeding remaining budget are rejected.

Example call: `budget_status()`

## fingerprint_lookup(code_hash: string)  [scope=read]

Novelty distance of a candidate against measured candidates and the
known-code table. Distance 0 = WL-indistinguishable; < epsilon is gated
from the slow loop as a near-duplicate.

Example call: `fingerprint_lookup(code_hash="a41f00b2")`

## known_code_lookup(code_hash: string)  [scope=read]

Equivalence-class lookup against the literature known-code table
(docs/known_codes_v1.json). A match means rediscovery, not novelty.

Example call: `known_code_lookup(code_hash="a41f00b2")`

## ledger_propose(predicate: array, claim: any, scope: any, rationale: string)  [scope=policy]

Propose an insight hypothesis. Predicate = conjunction of comparisons
over computed columns only; claim defaults to lower per_logical_per_round.
Rejected when the active-hypothesis cap is reached, the predicate matches
a graveyarded entry, or the schema is invalid. Adjudication is prospective:
only evidence arriving AFTER this proposal can support/refute it.

Example call: `ledger_propose(predicate=[{"field": "family", "op": "==", "value": "bb"}], claim={"metric": "per_logical_per_round", "direction": "lower"}, rationale="bb rows dominate the slow top-k this turn (S-4)")`

## ledger_retract(entry_id: string)  [scope=policy]

Retract an active hypothesis or supported entry (moves it to retired;
retired predicates cannot be re-proposed).

Example call: `ledger_retract(entry_id="H-7")`

## manual_read(section: string)  [scope=read]

Read one manual section. Sections live under the campaign manual
directory: static/ (tool catalog, the two-ledger semantics, feedback
vocabulary), dynamic/ (supported insights, bandit snapshot, latest
digest).

Example call: `manual_read(section="static/INDEX.md")`

## precheck_draft(program: string, rng_seed: integer)  [scope=draft]

Pre-check one construct program draft: sandbox -> structural -> proxy
-> fingerprint (novelty vs known codes). Returns machine-computed truths
only; passing precheck does NOT guarantee acceptance (the evaluator is
the source of truth).

Example call: `precheck_draft(program="def construct(rng): ...")`

## query_archive(family: any, max_n: any, min_d_proxy: any, max_check_weight: any, promoted_only: boolean, limit: integer)  [scope=read]

Structured query over the fast archive queue. Rows carry code_hash /
family / n,k,d_search / Q / max_check_weight, promotion flags and the
construction `spec` (group name, base-matrix shapes) so a query can compare
structures and not just scores; use query_evidence for one candidate's full
chain. `max_check_weight` filters to codes at or below a check weight.

This is the RUNTIME/MAP archive, ordered by the runtime acquisition key. It
is not the structural record: retention across turns is decided by the
(k, d_search, -max_check_weight) proxy-Pareto elites in S-3, which this
queue does not see.

Example call: `query_archive(family="lp_nonabelian", limit=8)`

## query_coverage(limit: integer)  [scope=read]

Structural coverage of the search so far: per region (family / group
class / group-order band) how many candidates were proposed, how many
carry a measurement, and how many racing stopped at pilot depth with their
performance still unresolved. Also lists lp_nonabelian catalog branches
that have never been proposed. Use it to find unexplored regions — a
ranked list can only show what was already tried.

Example call: `query_coverage()`

## query_evidence(code_hash: string)  [scope=read]

Full evidence chain for one candidate (code_hash prefix >= 8 chars):
slow rankings row(s) + distance evidence + racing metadata.

Example call: `query_evidence(code_hash="a41f00b2")`

</source>
