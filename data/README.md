# Data

| Directory | Content |
| --- | --- |
| `tables/` | The seven appendix tables (BO baseline top-three codes for both tasks, reciprocal evaluation, fixed-weight searches, ablation, BB reference codes, champion statistics), as `.tex` and `.csv` |
| `codes/` | One JSON record per code listed in Tables IX and X and in the seven appendix tables: parameters, construction, parity-check matrices H_X and H_Z, and the table rows the code appears in with its logical error rates |

Each directory has its own README describing the files and fields, and a `MANIFEST.md5` with the checksum of every file.
